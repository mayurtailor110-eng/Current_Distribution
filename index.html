Each branch is a series resistance from the common DC bus node to the common return. Current divides by conductance: Ii = Itotal · Gi / ΣG, with Gi = 1/Rbranch,i. This is the exact network result for equal-EMF parallel sources — never a proportional-to-length approximation.

Imbalance-reduction study

Imbalance is driven by the spread in branch resistance. Mathematically it is minimised by bringing every branch resistance toward the highest branch — achieved by padding shorter feeders. Model & assumptions

  • Topology (configurable). Two-level parallel network: N rack feeders in parallel at the combine-cabinet DC± nodes, and within each rack k strings in parallel sharing that rack's feeder. Each string is a series stack of packs (e.g. 104S1P packs, 4 or 8 in series). Switch between the two designs on the dashboard — Design 1 (12 racks × 1 string, single-string HV box) and Design 2 (6 racks × 2 strings, dual-string HV box) — or set racks, strings/rack and packs/string directly on the Input tab. With k = 1 this reduces exactly to the flat 12-branch current-divider.
  • Feeder carries combined string current. Because both strings in a dual-string rack share one feeder, that feeder carries k× a single string's current. Feeder ampacity and voltage drop are checked against the combined (feeder) current; the string cable and pack see the per-string current. The string-to-string current imbalance is driven by the feeder-length spread across racks; strings within a rack split evenly when identical.
  • Equal-EMF assumption. All strings are taken at the same open-circuit voltage (balanced SOC). Under this assumption the exact network solution is the conductance current-divider Ii=Itot·Gi/ΣG. Unequal SOC would add circulating currents not modelled here.
  • Steady-state, resistive. DC only; inductance, skin/proximity effect and transient sharing are not modelled.
  • Feeder loop. Positive and negative feeders of equal length ⇒ loop resistance = factor × ρL/A (default factor 2).
  • Equal branch V-drop. Node-to-node drop is identical across branches by construction; the reported per-branch drop is the feeder-cable portion, which varies.
  • Pack internal resistance dominates reality. With a realistic string resistance the cable-driven imbalance shrinks markedly. Default 0 shows the cable-only worst case the brief asks to expose.
